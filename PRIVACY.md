# Privacy notice — VCL Language Tools plugin

The VCL Language Tools plugin runs entirely inside your IDE. It does **not** collect, store or transmit any personal data,
usage statistics, telemetry or file contents, and it makes no network connections. Links in the quick-documentation
popup open the public Varnish or Fastly documentation (varnish-cache.org, fastly.com) in your browser only when you click them.

If you contact us through GitHub issues, GitHub's privacy policy applies to what you post there; we only use it to
answer your request.
